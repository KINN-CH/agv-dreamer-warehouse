# AGV 월드모델 — Cosmos는 충돌을 상상하는가

AGV가 장애물로 향할 때 Cosmos 3 Nano에게 명령(직진·정지)을 주고 1.6초 뒤를 상상시킨다.
Isaac Sim에서 같은 장면을 실제로 달려 본 결말과 비교한다.

## 실험 — 2×2

|  | 직진 명령 | 정지 명령 |
|---|---|---|
| **장애물 있음** | 실제: 부딪힌다 | 실제: 앞에서 선다 |
| **빈 장면** (대조군) | 실제: 지나간다 | 실제: 선다 |

**기준은 하나** — Cosmos의 상상이 같은 장면의 실제 결말 두 개(직진 / 정지) 중 **어느 쪽과 더 닮았나.**
빈 장면 두 칸은 대조군이다. 장애물이 없을 때 Cosmos가 명령을 따르는지, 비교 기준이 작동하는지 확인한다.

## 결과 (2026-09-24 본실험, 장면 50개)

|  | 직진 명령 | 정지 명령 |
|---|---|---|
| 장애물 있음 | **0/50** 명령대로 | 50/50 |
| 빈 장면 | 50/50 | 50/50 |

빈 장면에서는 두 명령을 모두 따랐다(대조군 통과). 장애물 앞 정지 명령도 따랐다.
단, 로봇 출발 자리가 늘 같아서 **빈 장면 50개는 사실상 같은 화면**이다(첫 프레임 차이가 밝기 1/255 수준).
빈 장면 50/50은 독립된 50번이 아니라 한 화면의 확인이다. 장애물 칸 50개는 종류·거리·좌우 위치가 장면마다 다르다.
장애물 앞에서 직진을 시키면 **50장면 모두 부딪히지 않는 미래**를 그렸다 — 상상 속 장애물이 거의 커지지 않는다.
장애물 종류(상자 2종 21장면 · 통 3종 29장면)와 관계없이 같았고, 가장 애매한 장면(0023)도
직진 결말과의 차이 0.64 > 정지 결말과의 차이 0.46이었다.
장면별 비교 그림 `results/scene_*.png`, 수치 `results/result.csv`. 9/23 예행연습 3장면(같은 결과)은 50장면에 포함돼 있다.

## 원인 확인 (2026-09-24) — 설정 탓인가, 모델 탓인가

**어떤 설정에서도 충돌은 0이었다 — 설정 탓이 아니다.** 장면 10개(장애물 5종 × 2)의 '장애물 + 직진' 칸만
설정을 하나씩 바꿔 다시 상상시켰다 (`src/cause.py`, 결과 `results/cause/`).

| 바꾼 것 | 충돌을 그림 | 빈 장면에서 직진 따름 (대조) |
|---|---|---|
| 없음 (본실험 설정) | 0/10 | 10/10 |
| ① 전진 액션 최대 (0.83 → 4) | 0/10 | 10/10 |
| ② seed 1 | 0/10 | 10/10 |
| ② seed 2 | 0/10 | **0/10** — 빈 장면에서도 직진을 안 따랐다. 원인 판단에서 뺀다 |
| ③ 문장에서 'empty' 한 단어 뺌 | 0/10 | 10/10 |
| ④ 문장에 "앞의 물체에 부딪힌다"를 씀 | 0/10 | — |
| ⑤ 문장에 "AGV 시점이고, 보이는 것은 실제 환경이라 모든 물체가 멈춰 있다"를 씀 (9/28) | 0/10 | 10/10 |

문장을 바꾼 ③④⑤는 영상 자체가 거의 그대로였다 — 기준 영상과의 차이가 밝기 평균 2~11(255 중)로,
seed만 바꿨을 때(13~18)보다 작다. 첫 화면과 명령이 있으면 Cosmos는 문장을 거의 따르지 않는다.

**그럼 대신 무엇을 그리나 — 장애물 자리를 가리고 배경만 비교했다** (`src/background.py`, 50장면, 결과 `results/background/`).
자는 빈 장면의 실제 직진·정지 영상이다. 장애물이 없으니 배경만으로 '카메라가 얼마나 갔나'를 말한다.

| 비교 | 배경이 직진 쪽을 닮음 | |
|---|---|---|
| 장애물 + 직진 상상 | **50/50** | 질문 |
| 빈 장면 + 직진 상상 | 50/50 | 대조 — 직진이어야 정상 |
| 장애물 + 정지 상상 | 0/50 | 대조 — 정지여야 정상 |
| 장애물 + 정지 실제 | 0/50 | 대조 — 실제로 0.5m 가서 선 영상에 자를 대 봤다 |

**상상 속 카메라는 명령대로 간다. 그런데 장애물이 같은 속도로 물러나서 크기가 그대로다.**
0초와 1.6초를 겹친 그림(`results/background/fig_ghost_0000.png`)에서 기둥은 실제 직진처럼 두 겹이고 장애물은 한 겹이다.

설정을 바꾸면 피하는 방식이 달라지기도 한다. seed 1에서는 10장면 중 5장면에서 카메라가 덜 갔다(스스로 느려졌다).
전진을 최대로 주면 장애물이 커지긴 해도 1.6초 안에 닿지 않았고, 장면 0005에서는 통이 로봇으로 바뀌어 멀어져 갔다
(`results/cause/fig_action4.png`). **어느 쪽이든 충돌은 그리지 않았다.**

추정(검증하지 않음): `av` 도메인은 차량 주행 영상으로 배웠다. 주행 영상에는 충돌이 거의 없고, 내 앞에 있는 물체는
대개 같이 달리는 앞차다. 그래서 "앞에 물체가 있는데 계속 간다"를 "앞차를 따라간다"로 그렸을 수 있다.

## 돌리는 법

```
[VM]   ssh <user>@<VM_IP>
       cd ~/agv/isaac && source ~/isaacsim-venv/bin/activate
       python gen_episodes.py --scenes 50 --out ./out
[AGX]  scp -r <user>@<VM_IP>:~/agv/isaac/out/ep_* /data/ch/agv-wm/data/incoming/
       source /data/ch/agv-wm/env.sh && agvrun src/experiment.py
       agvrun src/background.py      # 새 상상 없이 기존 영상만 — 몇 분
       agvrun src/cause.py           # 상상 90편 — 약 2시간 40분
```

한 장면에 상상 4편 × 약 106초 ≈ 7분. 이미 상상한 칸은 다시 돌리지 않는다.

## 구성

| 장비 | 역할 |
|---|---|
| RTX 5090 VM (`<host>`, Tailscale `<TAILSCALE_IP>`) | Isaac Sim 6.1 — 장면을 실제로 달려 정답 영상을 만든다 |
| AGX Orin 64GB | Cosmos 3 Nano — 상상 · 비교 (Nano 생성은 34GB라 5090의 32GB에 안 들어간다) |

```
src/experiment.py      2×2 실험 — 상상하고, 실제 결말 두 개와 비교해 표를 낸다
src/cause.py           원인 확인 — 실패한 칸만 설정을 하나씩 바꿔 다시 상상
src/background.py      배경만 비교 — 장애물을 가리고 카메라가 얼마나 갔나
src/scoring.py         영상 읽기 · 두 영상이 얼마나 닮았나
src/rollout.py         조건 프레임 + 액션 → Cosmos 상상
src/actions.py         전진 액션 (av 도메인)
src/calibrate.py       전진 보정 — 액션 값 → 상상 속 전진 거리 (results/calibrate_fd.json)
isaac/gen_episodes.py  VM용 데이터 생성기
```

모델: `/data/ch/models/cosmos3-nano` (33GB). 컨테이너 `cosmos3-edge:jetson`은 지우면 안 된다.
지난 시도(깊이 채점기, 선회 조건, 다단계 보정)는 `*/_이전시도/`에, 그 과정은 `docs/01-실측기록.md`에 있다.

## 설정과 근거

| 항목 | 값 | 근거 |
|---|---|---|
| 액션 | av 도메인, 전진(z)만, 회전 항등 | 규약은 Cosmos inverse dynamics로 확인 |
| 직진 1m/s | 스텝마다 0.826 | 보정: 이 값이면 빈 장면에서 실제 속도로 전진 |
| 시간 | 스텝당 1/15초 × 24 = 1.6초 | 실제 충돌은 1.1~1.67초 — 50장면 중 47장면이 1.6초 안, 나머지 3장면도 1.6초에 장애물과 7cm 이내 |
| 프롬프트 | 모든 칸에 같은 장면 묘사 한 문장 | 움직임·사물을 쓰면 상상이 문장을 따라간다 |

## 한계

- 본실험은 설정 하나로 쟀다(프롬프트 한 문장, seed 0, 20스텝, 1m/s). 원인 확인에서 액션·seed·문장을 바꿔 봤지만 장면 10개다
- 창고 한 곳, 로봇 출발 자리 하나다 — 빈 장면은 사실상 한 화면이다
- 같은 명령도 seed에 따라 다르게 그린다 — seed 2는 빈 장면에서도 직진을 따르지 않았다
- 기준은 "두 결말 중 어느 쪽과 닮았나"다. 둘 다 아닌 엉뚱한 상상도 둘 중 하나로 분류된다 — 비교 그림으로 확인한다
