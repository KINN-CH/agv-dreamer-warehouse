# Dreamer v5 — 다중 창고·깊이 전용 입력·실제형 통행 (10/8~10/9)

## 요약
충돌 예측은 **처음 보는 창고에서도 통한다**(AUROC 0.88~0.93, 단순 거리 기준을 넘음). 실제 주행(v5h2)은
**규칙보다 빠르고**(제시간 도착 58 vs 49) 사람·물체 충돌은 비슷하다(9 vs 7). 다만 전체 성공은 규칙보다 6장면 적다
(139 vs 145, 유의한 차이 아님). **아직 '규칙보다 낫다'고는 말할 수 없다.**

## 발견된 문제 및 수정
| 문제 | 원인(실험으로 확인) | 수정 |
|---|---|---|
| v5 AUROC 0.75 < 거리 기준 0.85 | **Isaac 카메라 기본 clipping 1m — 1m 안이 안 보임.** 충돌 864건 모두 충돌 순간 물체가 BEV에 없음 | clipping 0.05m (상자 0.6m: 0점 → 1,327점) |
| (정정) 예전 '범퍼 앞 0.9m 사각지대' | 물리 한계가 아니라 위 설정. v2·v4·규칙 모두 같은 핸디캡 | — |
| 옆 사각 | 카메라 3대(앞·뒤 모서리 ±120°) — 차체 1~2m 안 52%가 안 보임 | 4대(앞·좌·우·뒤) → 21% |
| 바닥 채널 잡음 | 깊이 160×120 + 바닥 점 1/8 | 1/2 (잡음 4.2→2.2%) |
| v5b 시범도 거리 기준 미달 | **지도(R) 채널이 방해** — G에 랙이 이미 다 찍히는데 화면 22%를 차지·위치 오차로 어긋남. 손실 가중치 조정은 오히려 악화 | 지도 채널 뺌 (시범 0.764 → 0.876) |
| 좁은 통로 제자리 회전 → 랙 쓸림 | 차체 뒤 1.03m가 반경 1.09m로 쓸림 | 공간 없으면 후진 경로 추종·앞뒤로 빼기 (막힘 s101 14→18/18) |
| 목적지 옆 작업자 → 길 없음 정지 | 서 있는 사람이 목적지를 막음 | 1m 안 빈 곳으로 가서 대기 |
| v5b가 갑자기 꺾는 사람을 놓침 | 앞보기 모드에서 규칙 정지 구역을 꺼 둠 | 혼합: 규칙 정지 구역(1.5m)을 최후 안전장치로 |
| 휜 경로에서 Dreamer가 계속 정지 | 후보 = 곡률 유지 → 상자 쪽으로 상상 | 후보 = 경로를 그 속도로 2초 따라가는 행동열 |
| 서 있는 사람과 서로 기다림 | Dreamer는 가까운 사람만 보면 정지 | 4초 넘게 정지 + 정지 구역 비면 0.3m/s로 지나감 |
| Dreamer 후진으로 랙 충돌 | 후진할 때 뒤 확인 없음 | 뒤 1m·랙 확인 후 후진 |

## 남은 과제
1. v5h2 실패 23장면(시간초과 12 · 사람·물체 충돌 9 · 랙 2) 중 규칙만 성공한 15장면 분석. 랙 충돌 2건은 '안전한 후진' 뒤에도 남음 → 원인 확인 필요.
2. 판단 지연 100~150ms — 평가 때 6개 병렬로 CPU를 나눠 쓴 탓(실기기 10~30ms 예상). 지연이 결과에 주는 영향 확인 필요.
3. 원래 Dreamer 방식(보상으로 운전 정책 학습)은 아직 안 함 — 속도 점수(규칙 기반)는 실패.
4. 차체 모서리 0.5m 안 사각(4대여도 54%) — 모서리 광각 배치 검토.
