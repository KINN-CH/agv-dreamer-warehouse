# 데이터 규격 — VM(Isaac Sim) → AGX(Cosmos)

`isaac/gen_episodes.py`가 이 형식으로 내놓고 `src/experiment.py`가 읽는다.

## 에피소드 정의 (장면 1개 × 명령 1개)

```
data/incoming/
  ep_0000_straight/     장면 0000, 직진 명령
  ep_0000_brake/        장면 0000, 정지 명령 (같은 장애물·같은 위치)
    cond.png            조건 프레임 — 이 장면에서 Cosmos에게 주는 첫 장면
    future.mp4          실제 결말 2초 (30fps)
    cond_empty.png      같은 자리에서 장애물만 치운 조건 프레임
    future_empty.mp4    장애물 없이 같은 명령으로 달린 2초
    meta.json
```

## meta.json

| 키 | 뜻 |
|---|---|
| `scene` | 장면 번호. 같으면 같은 장애물·같은 위치 |
| `steer` | `straight`(1m/s 직진) 또는 `brake`(1m/s에서 감속해 정지) |
| `v_mps`, `brake_mps2` | 속도, 정지 감속 (brake만) |
| `fps`, `horizon_s` | future.mp4의 프레임률과 길이 |
| `collision`, `ttc_s`, `min_dist_m` | 실제로 부딪혔나, 몇 초에, 최소 거리 |
| `obstacle`, `obstacle_dist_m`, `lateral_m` | 장애물 종류, 조건 프레임 때 앞면까지 거리, 좌우 치우침 |

future.mp4의 k번째 프레임은 조건 프레임으로부터 (k+1)/30초 뒤다. 실험은 2프레임 간격으로 잘라
Cosmos 상상(스텝당 1/15초)과 같은 시점끼리 비교한다.
